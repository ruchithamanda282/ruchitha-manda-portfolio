# Ruchitha Manda — Portfolio

A single-file personal portfolio with a warm editorial design (paper texture, serif display type, terracotta accents).

## Files

- `index.html` — the whole site (styles and scripts inline, no build step)
- `Ruchitha_Manda_Resume.pdf` — linked from the "Resume" button in the nav

## Preview

Open `index.html` in any browser.

## Deploy to GitHub Pages

1. Create a repo (e.g. `ruchitha-manda-portfolio`) and push these files to `main`.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Live at `https://<your-username>.github.io/ruchitha-manda-portfolio/`.

## Notes

- The contact form validates inputs, then opens the visitor's mail app with a message pre-addressed to ruchithamanda1199@gmail.com. For true server-side delivery, wire up EmailJS (emailjs.com) or Formspree in the form script.
- No certifications are claimed anywhere on this site — only credentials she holds.
